# Gemini Notebook 専属家庭教師ガイド

GitHub Pages でそのまま公開できる静的HTML資料です。

## 公開方法

1. このZIPを解凍します。
2. 解凍後フォルダの **中身（index.html / README.md）** を、GitHubリポジトリ直下へアップロードします。
3. GitHub Pages を `main / root` で有効化します。

## 推奨リポジトリ名

`gemini-notebook-ai-tutor-guide`

## 印刷

ブラウザで `index.html` を開き、上部の「A4で印刷 / PDF保存」からA4縦で保存できます。

## フォント

Google Fonts 経由で Klee One / Yusei Magic / Caveat を読み込みます。ネットワークに接続できない場合はOS標準フォントへフォールバックします。
